# 60系统页面生成规范

> 本文档适用于所有 AI 工具（Claude Code、WorkBuddy、TRAE Work CN 等）和人工开发。
> 使用 AI 工具时，将本文档内容粘贴到对话开头或系统提示中即可生效。

---

## 核心原则

**先选模板 → 再查组件与尺寸 → 最后写业务差异**

三步必须按顺序执行，不得跳过。

---

## 第一步：选场景模板

根据页面意图，从以下场景模板中选择最接近的一个作为起点。

**禁止**：不选场景模板直接生成页面，或参考其他业务页面作为模板。

场景模板文件位于 `common/60/ui-demo/scenarios/`：

## 第二步：查组件样式与骨架尺寸

组件样式文件位于 `common/60/ui-demo/components/`，生成页面时需要参考对应组件的样式和类名：

| 文件名 | 组件 |
|--------|------|

| `form-input-states.html` | 输入框（ds-input） |
| `form-select-states.html` | 下拉选择（ds-select） |
| `form-checkbox-group-states.html` | 复选框（ds-checkbox） |
| `form-radio-group-states.html` | 单选框（ds-radio） |
| `form-switch-states.html` | 开关（ds-switch） |
| `form-date-picker-states.html` | 日期选择（ds-date-picker） |
| `form-upload-button-states.html` | 上传（ds-upload） |
| `basic-table-page.html` | 基础表格 |
| `modal-components.html` | 弹窗（ds-modal） |
| `tag-components.html` | 标签（ds-tag / ds-process-tag） |

## 第三步：写业务差异

- **原型阶段**（`common/60/ui-demo/demos/`）：HTML 只组合现有 `ds-*` 类名，CSS 只写页面布局和专属可视化
- **实际业务**（`60sysV2/pages/`）：沿用原型阶段的组件样式，业务 CSS 只写页面布局和专属可视化

---

## 强制禁止清单

以下行为一律禁止：

1. **禁止复制 `.ds-*` 组件内部 DOM**，或覆盖 `.ds-*`、`.frame2-*` 样式
2. **禁止复制其他业务页面**的 CSS、JS、Mock 数据或页面组件
3. **禁止把页面专属实现放进公共 `common/` 目录**以规避独立性检查
4. **禁止修改已锁定的旧静态页面**（需要改动时先评估影响范围）
5. **禁止使用 Web Components**（如 `<ds-data-table>`）— 60sysV2 通过 file:// 协议访问，不支持 ES modules
6. **禁止从空白文件开始手写通用页面** — 必须从场景模板出发

---

## 60sysV2 技术限制

由于 `60sysV2/pages/` 通过 file:// 协议直接访问 HTML 文件：

### 不支持
- **Web Components**：`<ds-data-table>` 等基于 Lit 框架的组件需要 ES modules，file:// 下会被 CORS 拦截
- **ES modules**：`<script type="module">` 和 `import` 语法在 file:// 下无法工作

### 允许
- **普通 HTML 标签**：`<table>`、`<button>`、`<input>`、`<select>` 等
- **ds-* CSS 类名**：引用 ui-demo 的组件样式文件，使用 `ds-button`、`ds-tag`、`ds-filter-area` 等类名
- **普通 JavaScript**：`<script>` 标签内的常规 JS 代码

### CSS 引用示例

```html
<!-- 引用 ui-demo 的组件样式（注意相对路径层级） -->
<link rel="stylesheet" href="../../../../../common/60/ui-demo/packages/design-system/src/base.css" />
<link rel="stylesheet" href="../../../../../common/60/ui-demo/packages/design-system/src/Button/index.css" />
<link rel="stylesheet" href="../../../../../common/60/ui-demo/packages/design-system/src/Tag/index.css" />
<link rel="stylesheet" href="../../../../../common/60/ui-demo/packages/design-system/src/Field/index.css" />
<link rel="stylesheet" href="../../../../../common/60/ui-demo/packages/design-system/src/FilterBar/index.css" />
<link rel="stylesheet" href="../../../../../common/60/ui-demo/packages/design-system/src/Tabs/index.css" />
<link rel="stylesheet" href="../../../../../common/60/ui-demo/packages/design-system/src/RegularListTemplate/index.css" />
```

```html
<!-- 使用 ds-* 类名 -->
<button class="ds-button ds-button--primary ds-button--default-size">查询</button>
<span class="ds-tag ds-process-tag ds-process-tag--filled ds-tag--success">已通过</span>
```

### 路径引用规则

`60sysV2/pages/` 下页面引用 `jjr/common/` 需向上 4 级：
```
../../../../../common/60/ui-demo/...
```

## 页面跳转规范

使用 `window.location.href` 进行页面跳转：

```javascript
// ✅ 同级页面跳转
window.location.href = 'print-report.html';

// ✅ 跨目录跳转（使用相对路径）
window.location.href = `../apply/leave-cancel-detail.html?id=${id}&mode=view`;

// ✅ 带参数跳转（使用 URLSearchParams）
const params = new URLSearchParams({ id: recordId, mode: 'edit' });
window.location.href = `../info-audit-detail/index.html?${params.toString()}`;

// ❌ 禁止硬编码绝对路径
window.location.href = '/pages/leave/query/index.html';

// ❌ 禁止在 HTML 中硬编码跳转
// <a href="../other/page.html">跳转</a>
```

## 页面依赖限制

每个页面只允许依赖：
- **框架文件**：`common/60/ui-demo/framework/`
- **组件样式**：`common/60/ui-demo/assets/`（tokens.css、base.css、theme.css）
- **当前页面目录内的文件**

禁止依赖其他业务页面的 CSS、JS 或组件，禁止依赖未登记的第三方库。

## UI 细节规范

### 页面背景
- 系统菜单页面背景色必须为白色 `#fff`，不是灰色 `#f0f2f5`

### 页面标题
- 业务页面不要显示 H1 标题和副标题，直接从 Tabs/筛选/表单分区开始

### 查询/重置按钮
- 重置（default）在前、查询（primary）在后
- 适用于列表页、弹窗、二级页

### 操作列
- 列表页表格操作列放在最右侧
- 操作列中编辑和删除之间用竖线分隔

### 标签样式
- 使用 `ds-process-tag` 规范组件
- 4px 圆角 + 语义色（success `#1fb09d` / warning `#d86617`）
- 不用胶囊样式

### 分页
- 列表页分页组件必须固定在页面最底部，不随表格滚动
- 分页样式参考 `regular-list-page.html` 中的 `preview-pagination` 结构

### 表格
- 有表格的页面表格内部滚动，页面不要滚动条

### 间距与行高
- 内容左右内边距 `12px`；筛选区 → 工具栏 `12px`；工具栏 → 表格 `8px`；表格 → 分页 `8px`；分页 → 底部 `8px`
- 数据表格：表头高 `40px`，其余数据行高 `46px`；表格式字段（标签+控件的表单单元）行高 `40px`，不属于此规则
- 控件高（筛选输入、下拉、按钮、工具栏）统一 `32px`；同组按钮间距 `4px`
- 区域只允许使用 tokens 已有的数值，不自造 10/14/18/24
- 不在页面里重复声明 tokens 已给对的尺寸（`--ds-regular-list-inset`、`th`/`td` 高度）；确需偏离时在页面注释写明理由

### 弹窗
- 通过/退回/不通过必须用审核意见弹窗，不要用 confirm 确认框

### 蓝色文字按钮
- 蓝色文字操作按钮统一用 `#3167ff`，不用 `#1677ff`

### 删除按钮
- 删除按钮统一用蓝色主色，不用红色

## 完成后校验清单

交付前必须逐项检查：

### 结构检查
- [ ] 页面使用了场景模板作为起点
- [ ] 组件样式使用了 ds-* 类名（按钮、标签、筛选区等）
- [ ] 没有复制其他页面的代码
- [ ] **60sysV2**：使用普通 HTML 标签（table、button、input 等）

### 样式检查
- [ ] 没有覆盖 .ds-* 或 .frame2-* 样式
- [ ] 业务 CSS 只包含布局和专属可视化
- [ ] 页面背景色为 #fff（非 #f0f2f5）
- [ ] 计算样式实测：内容左右内边距 12px、表头 40px、数据行 46px
- [ ] 页面未重复声明 tokens 已给对的尺寸
- [ ] 骨架数值集中在页面根容器的常量变量（或直接写在骨架选择器里），不散落到业务规则

### 跳转检查
- [ ] 使用相对路径，未硬编码绝对路径
- [ ] 参数使用 URLSearchParams 拼接
- [ ] 跳转目标页面存在

### 链接检查
- [ ] 所有 CSS/JS 引用路径正确
- [ ] 图片、图标等资源路径正确
- [ ] 页面可在浏览器中正常打开

### 独立性检查
- [ ] 页面不依赖其他业务页面的代码
- [ ] 页面专属实现未放入公共目录

**任一检查项失败都不能交付。**
