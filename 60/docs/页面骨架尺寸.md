### 2.1 regular-list-page（常规列表 · 上下布局）
- **顺序**：页签或提示条（可选）→ 筛选 → 工具栏 → 表格 → 分页
- **数值**：12 内边距 / 顶 12 / 筛选→工具栏 12 / 工具栏→表格 8 / 表格→分页 8 / 分页→底 8

### 2.2 tree-config-page（左树右表 · 左右布局）

## 3. 不需要粘贴常量块（旧做法已废弃）

用 `ds-regular-list-template` 骨架或 DS `DataTable` 的页面，**一行尺寸都不用写**——tokens 已经给了 12 / 40 / 46，模板继承即可。旧版本这里让人往 `.page-wrap` 里粘 `--page-inset: 12px`、往 `.ds-regular-list-template` 里塞 `--ds-regular-list-inset: 12px`，属于重复声明，已删除。

唯一需要动手的情况：页面**自造表格**（不走 DS `DataTable`，如 `.basic-table` / `.ht-table`）。此时不要写字面值，直接引用 tokens 变量：

```css
.basic-table th { height: var(--ds-table-header-height); }
.basic-table td { height: var(--ds-table-row-height); }
```

自造表格的行高必须与数据表格一致；`padding` 不再叠加纵向值（`th`/`td` 的 `height` 是最小值，纵向 padding 会把 46 撑到 49，`archive-transfer` 就是这样跑成 49）。

**更正**：旧版本写的「不要给 DS 表格设 `--ds-table-row-height`，因为 th/td 共用」是错的。`DataTable/index.css` 里 `th` 有单独的 `height: var(--ds-table-header-height)` 覆盖，两个变量各管一层。

## 4. 生成后自检（交付前逐条跑）

1. **行高**：页面 CSS 存在表头 40、数据行 46；不出现 `--ds-table-row-height`。
2. **内边距**：根内容容器左右为 12（或模板变量 `--ds-regular-list-inset: 12px`）。
3. **区域间距**：出现 12（筛选→工具栏）、8（工具栏→表格、表格→分页）、8（分页→底）；无自造值。
4. **底部**：分页固定在内容区底部，表格内部滚动，页面无纵向滚动条。
5. **60sysV2**：`ds-data-table` = 0、`type="module"` = 0、body 背景 `#fff`、页面映射已登记。

任一条不过，不交付。
