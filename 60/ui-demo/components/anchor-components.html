Anchor / DSAnchor

锚点固定在内容侧边，点击后跳转到对应章节。当前章节使用主色文字、浅主色背景和左侧指示线。

右侧锚点

Right Placement

右侧目录导航

右侧锚点用于内容区右栏目录，基线和选中指示条靠右，文本右对齐。适合详情页、帮助文档和表单分组页。

右侧章节定位

组件通过 `placement="right"` 或 `.ds-anchor--right` 启用右侧样式，保留默认、选中、悬浮、禁用和多级缩进能力。

使用说明

React / HTML

组件落地规则

React 页面使用 `DSAnchor`；HTML 预览页可直接复用 `.ds-anchor`、`.ds-anchor__item`、`.ds-anchor__link` 这些类。组件颜色统一来自 `tokens.css`。

适用场景

详情页章节定位、复杂表单分组、审核页分段导航、帮助文档目录、长列表快捷跳转。
