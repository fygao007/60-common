下拉选择

基于 MasterGo 选择器设计稿扩展 DSSelect，覆盖单选、多选、搜索、清除、下拉面板、禁用、错误和空数据状态。

基础状态

Default / Hover / Focus / Disabled / Error

未选择

默认使用占位文字和下拉箭头。

已选择

有值时展示正文色，可显示清除按钮。

聚焦

聚焦态使用主色边框和浅主色投影。

禁用

禁用态不可点击，背景和文字置灰。

错误

错误态使用危险色边框，可配合字段错误提示。

搜索输入

搜索态在触发器内输入关键词。
