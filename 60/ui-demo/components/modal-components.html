弹窗组件

DSModal：统一配置、确认和编辑表单弹窗的尺寸、结构、关闭约束、焦点管理与提交状态。

交互示例

三个入口分别覆盖 MasterGo 集中配置稿、小型确认框和正文滚动。打开后可测试遮罩、Escape 和 Tab 焦点循环。

集中配置弹窗

中型 600px，内容自适应高度；结构与本次 MasterGo 规范一致。

操作确认弹窗

小型 480px，危险操作期间禁止遮罩和 Escape 误关闭。

长表单弹窗

中型 600px、固定最大高度；标题和底栏固定，仅正文滚动。

尺寸规则

宽度使用预设，高度由内容决定；只有需要固定工作区的长表单才显式传入高度。

规格宽度适用场景高度规则
small480px确认、警告、短反馈内容自适应
medium600px默认配置、短表单内容自适应；本稿示例 484px
large800px复杂表单、表格或对照内容最大高度为视口减 48px
wide900px双列短表单编辑模板示例 480px，窄屏自动单列

交互规则

以下规则已固化到 DSModal，而不是交给每个业务页面重复实现。

关闭关闭图标、取消、遮罩和 Escape 统一触发 onCancel；提交中全部锁定。
焦点打开后焦点进入弹窗，Tab 在弹窗内循环，关闭后返回原触发按钮。
滚动弹窗打开时锁定页面滚动；超高内容只滚动正文，标题和底栏保持可见。
