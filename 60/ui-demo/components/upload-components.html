上传组件

通过点击、拖拽或粘贴选择文件，覆盖上传进度、成功、失败、预览、下载、删除与重试。

设计来源：mastergo://getd2c/139272150501659-1259-36938

按钮上传与文字列表

选择文件 / 进度 / 预览 / 下载 / 删除

基础附件上传

支持多文件上传，单个文件不超过 20MB

选择文件后进入上传中状态，进度完成后展示预览、下载和删除操作。

初始成功与失败状态

失败文件支持重新上传，成功文件支持操作按钮。

图片 / 文件卡片 / 拖拽 / 粘贴
