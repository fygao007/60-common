# 发展方案流程动态需求说明

> 场景：`teacher-growth-process-dynamics`　版本：`1.0.0`　由产品世界模型生成，请勿手工维护重复副本。

## 目标

1. 在查看方案详情或台账时快速掌握审批进度、操作人、时间与意见

## 用户角色

- 管理部门（manager）

## 当前痛点

1. 流转记录与业务详情分离，难以同时查看
2. 列表中需要额外进入详情才能查看处理历史

## 场景流程

### 前置条件

1. 方案台账与确认详情使用现有发展方案流转记录

### 主流程

1. 在确认详情页右侧查看当前节点及历史流转
2. 在方案台账行操作中点击流程动态
3. 在抽屉中切换流程动态与流程图视图
4. 展开或收起单个节点以查看操作人、时间和审核意见

### 异常流程

1. 无流转记录时展示空状态
2. 后端流程定义未接入前，流程图只按现有流转记录展示实际发生的节点，不补造未发生的审批节点

## 业务规则

1. 复用已存在的方案事件，不增加业务字段或复制其他 Demo 的代码
2. 时间轴状态标签使用设计系统 DSTag 与统一流程状态色
3. 流程动态区域必须适配详情页侧栏和列表页抽屉两种承载方式
4. 列表入口使用设计系统按钮；抽屉使用设计系统 DSDrawer 与 DSTabs

## 验收标准

1. 台账每条方案均可打开流程动态抽屉
2. 抽屉可在流程动态与流程图之间切换
3. 确认详情页在宽屏右侧显示同一流程动态时间轴，窄屏下顺序回流
4. 时间轴节点可独立展开或收起并显示现有操作人、时间和意见
5. 流程状态标签按未开始、待审核、通过、退回、不通过等语义显示对应颜色

## 待确认问题

1. 正式流程图节点与分支需以后端流程定义为准；当前演示只基于已有方案流转记录展示，不新增或伪造审批事件
