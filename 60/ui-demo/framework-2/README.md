# 框架2

框架2是独立的后台系统壳模板，入口文件为 `shell.html`。

## 内容

- 顶部导航：深圳职业技术大学 Logo、系统标题、应用切换、搜索、用户菜单。
- 左侧导航：分组菜单、折叠导航。
- 页签区：页签切换、关闭、刷新当前页签、全屏工作区。
- 操作区：框架页默认留空，业务页面可自行注入内容。
- 主题：框架2独立主题变量位于 `theme.css`。

## 入口

- 纯框架预览：`shell.html`
- 业务示例：首页 `index.html`、基本信息页 `basic-info.html`、基本信息表格 `basic-info-table.html`
