缺省页组件

DSEmptyState / DSEmptyGuide：统一基础缺省图片、恢复操作和高级步骤引导。

基础缺省图

图片固定 100 × 100，图片与文字间距 8px；基础态默认只展示一行语义文案。

恢复操作逻辑

仅在用户能立即恢复当前状态时展示操作。切换场景后点击操作，观察状态变化。

高级空状态引导

支持指定操作、多个步骤、推荐方案和底部跳过入口；业务状态由外部受控。

使用规则

先匹配原因区分无数据、无结果、无权限、网络异常、维护中和加载失败，禁止统一使用“暂无数据”。
操作必须可恢复搜索提供清除筛选，异常提供重试；纯提示状态不放无效按钮。
高级引导受控步骤完成、跳过和加载状态由业务传入，组件只负责展示和触发回调。
