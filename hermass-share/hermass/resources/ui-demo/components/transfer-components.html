穿梭框

基于 MasterGo 组件规则生成 DSTransfer，统一平铺、分组、表格和树形数据的选择与回退交互。

设计来源：mastergo://getd2c/195991886967017-11-076878

平铺字段

搜索 / 全选 / 移除 / 清空

勾选左侧字段后立即加入右侧；搜索只过滤待选区，不改变已选结果。

分组字段

分组全选 / 展开收起

分组标题承载整组选取，字段仍可逐项加入，适合报表字段和权限配置。

表格穿梭

筛选区 / 多列数据 / 已选表格

复杂对象使用列配置呈现；待选表和已选表保持相同字段语义。

树形穿梭

层级缩进 / 节点展开收起

树节点保留层级和展开状态，适合组织、菜单和分类目录选择。
