选人组件

弹窗式选人组件，支持组织架构树、人员列表搜索、多选、已选列表管理，适用于审批人选择、通知发送对象等场景。

基础状态

Default / Filled / Disabled / Error

未选择

默认展示占位文字，点击打开选人弹窗。

已选择（单选）

选中后显示人数徽章和人员姓名。

已选择（多选）

多选时显示人数徽章，姓名超过2人显示省略。

禁用

禁用态不可点击，背景和文字置灰。

禁用（有值）

禁用态有值时仅展示，不可修改。

错误

请选择审批人。

表单行示例

Form Field
审批人

点击打开选人弹窗，支持组织架构筛选、姓名/工号搜索、多选。

当前值 未选择
