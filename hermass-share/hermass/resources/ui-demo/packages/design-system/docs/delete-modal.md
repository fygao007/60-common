## 场景流程

1. 用户点击表格行内“删除”。
2. 系统打开二次确认弹窗，明确展示删除对象和不可恢复提示。
3. 用户取消：关闭弹窗，不产生数据变更。
4. 用户确定且删除成功：关闭弹窗、移除数据并反馈成功。
5. 用户确定但数据已被引用：切换为删除失败弹窗，展示失败原因。

## 组件映射

| 区域 | 设计系统组件 | 配置 |
|---|---|---|
| 删除入口 | `DSButton variant="link" danger` | 表格行内删除 |
| 遮罩与弹窗 | `DSModal` | `480px` 宽，居中 |
| 警告图标 | Warning 图标 | 橙色圆形感叹号，`24px` |
| 错误图标 | Error 图标 | 红色圆形叉号，`24px` |
| 关闭操作 | `DSIconButton` | `16px` 关闭图标 |
| 取消/关闭 | `DSButton variant="default"` | 次操作 |
| 删除确定 | `DSButton danger` | 危险主操作 |

## 删除确认状态

- 弹窗尺寸：`480px × 134px`。
- 遮罩：`rgba(0,0,0,.2)`。
- 弹窗圆角：`8px`。
- 弹窗边框：`1px solid #F6F6F7`。
- 标题栏：`12px 20px`，警告图标、标题、关闭按钮横向排列。
- 警告图标：`24px × 24px`，颜色 `#FF913B`。
- 标题：`16px / 24px / 600`，示例“确定删除该科目吗？”。
- 说明：`14px / 22px`，颜色 `#505266`，必须包含具体对象名称和“删除后不可恢复”。
- 底栏：`12px 20px`，按钮右对齐，间距 `8px`。
- 确定按钮：背景 `#FA5151`，白色文字。

## 删除失败状态

- 沿用 `480px` 弹窗宽度、遮罩、圆角和关闭按钮。
- 标题前使用 `24px` 红色错误图标。
- 标题固定为“删除失败”。
- 正文格式：“失败原因：{具体原因}”。
- 底部只保留一个“关闭”次按钮，不继续显示危险操作。
- 失败后原数据必须保留。

## 行为规则

- 删除是不可逆危险操作，必须二次确认。
- 标题和说明必须明确对象，禁止只写“确认删除？”。
- 确定按钮使用危险色，不能使用普通主色。
- 点击遮罩、右上关闭、取消或按 `Escape` 均关闭当前弹窗。
- 请求提交期间应禁用重复提交；本模板未展示加载态，具体视觉沿用按钮组件。
- 后端拒绝删除时，不关闭后静默提示；应在弹窗中展示失败原因。
