- HTML：`.mastergo/195991886967017-2-003917/195991886967017-2-003917.html`

这份文档记录右侧表单抽屉的结构、组件状态、尺寸与间距。设计稿只包含抽屉面板，通用实现仍保留遮罩和焦点管理。

## 抽屉结构

1. 抽屉面板：`900px × 820px`，白色背景，左侧 `1px solid #F6F6F7`，内容溢出隐藏。
2. 标题栏：标题在左、关闭按钮在右。
3. 内容区：横向内边距 `20px`，上半部分为双列表单，下半部分为通栏文本域。
4. 底部操作栏：右对齐，包含“取消”“保存”“保存并新增”。

## 组件映射

| 模板区域 | 设计系统组件 | 本模板配置 |
|---|---|---|
| 抽屉容器 | `DSDrawer` | `placement="right"`，宽度 `900` |
| 标题栏 | `DSDrawer` header | `16px / 24px / 600` 标题 + 关闭图标按钮 |
| 关闭操作 | `DSIconButton` | `16px` 关闭图标，点击关闭抽屉 |
| 表单字段 | `DSField` | 标签宽 `94px`，标签与控件间距 `16px` |
| 选择器 | `DSSelect` | 默认空值、禁用有值两种状态 |
| 单行输入 | `DSInput` | 默认空值状态 |
| 多行输入 | `DSTextarea` | 空值、字数统计、右下角缩放标识 |
| 必填标记 | `DSField required` | 标签前红色 `*` |
| 底部操作 | `DSButton` | 两个次按钮 + 一个主按钮 |

带分组抽屉使用 `DSDrawer size="medium"`（`600px`），内容由 `DSFormGroup`、`DSEditForm` 和 `DSEditField` 组合。精确规则见 `docs/edit-overlay-templates.md`。
业务页面应直接使用 `DSGroupedEditDrawer`，不要自行覆盖 `DSDrawer` 宽度或复制分组间距。

- 抽屉背景：`#FFFFFF`。

## 表单布局规则

- 宽屏时使用双列字段布局；每列可在 `370px` 至 `600px` 间伸缩。
- 单行字段标签固定 `94px` 并右对齐，控件占据剩余宽度。
- 双列字段使用 `16px` 列间距和 `20px` 行间距。
- 文本域使用通栏布局，标签仍保持 `94px` 宽。
- 文本域标签顶部按 `6px` 对齐首行文字。
- 内容超出可视高度时应由抽屉内容区滚动，标题栏和底栏保持固定。

## 稿件注意事项

- D2C 原稿中存在三个绝对定位的“请输入”文本，与对应输入框占位内容重叠。它们按生成结果判断属于设计导出冗余，不应在实现中重复渲染。
- 稿件未展示遮罩层，不能据此取消 `DSDrawer` 的通用遮罩。
- “保存”在本稿中是次按钮，“保存并新增”是唯一主按钮，应保持单主操作原则。

## 通用交互

- 默认支持遮罩和 `Escape` 关闭，可用 `maskClosable`、`keyboard` 关闭。
- 打开后焦点进入抽屉，`Tab` 在抽屉内循环，关闭后返回触发元素。
- 打开时锁定页面滚动，正文超高时只滚动内容区。
- 传入 `onOk` 时默认底栏为“取消 + 确定”；未传 `onOk` 时保留单个“关闭”按钮，兼容详情抽屉。
- `confirmLoading` 会锁定所有关闭入口并展示确定按钮加载状态。
- `size="medium"` 为 `600px`，`size="large"` 为 `900px`，`width` 可覆盖预设。
