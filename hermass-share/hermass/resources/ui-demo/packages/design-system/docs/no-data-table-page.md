# 无数据表格页模板

来源：`mastergo://getd2c/195991886967017-2-016401`

原始 D2C 落盘：

- HTML：`.mastergo/195991886967017-2-016401/195991886967017-2-016401.html`
- 图片与图标：`.mastergo/195991886967017-2-016401/asset/`

这份文档是操作区“无数据表格页”的实现基准。业务文案和列定义可以替换，结构、组件状态、尺寸与间距应优先复用。

## 页面结构

1. 页面画布：`1196px × 820px`，四周 `12px`。
2. 操作区卡片：纵向布局，圆角 `12px`，内容背景 `#FFFFFF`，溢出隐藏。
3. 筛选区：渐变背景，顶部左右 `16px`、底部 `8px`。
4. 主内容区：左右 `16px`，工具栏与表格纵向间距 `12px`。
5. 表格区：表头、空状态内容，边框 `1px solid #EEEEF0`。
6. 分页区：固定高度 `64px`，内边距 `12px 16px`。

## 组件映射

| 模板区域 | 设计系统组件 | 本模板配置 |
|---|---|---|
| 筛选容器 | `DSFilterBar` | 多字段、可换行、展开状态 |
| 筛选字段 | `DSField` + `DSInput` | 标签右对齐，输入框默认空值 |
| 筛选辅助操作 | `DSIconButton` | 仅图标的默认态按钮 |
| 重置/查询 | `DSButton` | 次按钮 + 主按钮 |
| 展开控制 | `DSButton variant="link"` | 主色文字 + 向上箭头 |
| 表格操作区 | `DSDataTable.toolbarActions` | 普通按钮、带下拉箭头按钮 |
| 表格工具 | `DSDataTable.tableTools` / `DSIconButton` | 两个无边框图标按钮 |
| 表格 | `DSDataTable` | 复选框列、5 个业务列、空数据 |
| 空状态 | `DSDataTable.emptyRender` / `DSEmptyState` | 100px 图片 + “暂无数据” |
| 分页 | `DSPagination` | 总数、每页条数、页码、跳页 |

## 空数据行为

- 数据为空时仍展示完整表头，不隐藏表格结构。
- 空状态在表格剩余内容区水平、垂直居中。
- 本模板仍展示分页条；总数和页码是模板占位数据，业务实现必须使用真实数据。
- 空状态不附带创建按钮或说明文案，只有图片和“暂无数据”。
